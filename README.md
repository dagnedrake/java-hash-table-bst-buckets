# Java Hash Table Using BST Buckets

Java hash table implementation using binary search trees for collision buckets.

## Status

This repository is currently unfinished.

This is a Java project implementing a hash table with binary search tree 
collision buckets. I chose this project as a way to refresh my memory of 
working with Java data structures. I worked through the structure manually 
without the aid of a dedicated Java IDE, so the current version still 
needs compilation checks, debugging, cleanup, and formal tests.
